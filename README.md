# Faye’s Grade 5 Theory

Self-study ABRSM music theory app for Faye, as a single-page web app (`index.html`), plus printable PDFs.

- `index.html`: the app (works offline once loaded; progress is saved in the browser on each device).
- `downloads.html`: page listing the PDFs.
- `pdfs/`: Lesson packs 1: Grades 1–3 recap (Days 1–14), Lesson packs 2: Grade 4 (Days 15–29), Lesson packs 3: Grade 5 (Days 30–48), Lesson packs 4: Exam practice (Days 49–60), Practice papers, Grades 3, 4 and 5 (10 papers, with marking keys), Question bank, Grades 3, 4 and 5 (with answers), Reference book, Grades 1–5 (keys, scales, intervals, chords, ornaments, instruments, terms).

Deploy: static site, publish directory is the repo root (no build step).
